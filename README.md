# 🚀 AI Roadmap Generator

An AI-powered web app that generates structured learning roadmaps based on your goal and timeline.

## 🔥 Features
- Generate monthly and weekly learning roadmap
- Get daily actionable tasks
- Project suggestions at each stage
- Clean UI built with Streamlit

## 🧠 Tech Stack
- Python
- Streamlit
- OpenRouter API (GPT-4.1 Nano)

## 🚀 How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
